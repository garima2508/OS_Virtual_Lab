# SRMIST Virtual OS Laboratory Experiment Catalog

The laboratory is organized into 9 academic modules aligned with B.Tech CSE curricula:

| Module | Code | Title | Experiments & Algorithms Included | CO Mapping |
| :--- | :--- | :--- | :--- | :--- |
| **01** | `MOD-LINUX` | **Linux / UNIX Environment** | Shell Commands (`ls`, `ps`, `chmod`, `cat`), Process Control, System Calls | CO1 |
| **02** | `MOD-PROC` | **Process Management** | Process Lifecycle, `fork()`, `wait()`, `exec()`, Threads vs. Processes | CO1, CO2 |
| **03** | `MOD-CPU` | **CPU Scheduling** | FCFS, SJF (Non-preemptive), SRTF (Preemptive), Priority, Round Robin (Quantum) | CO2 |
| **04** | `MOD-SYNC` | **Process Synchronization** | Critical Section, Mutex, Semaphores, Producer-Consumer, Dining Philosophers | CO2, CO3 |
| **05** | `MOD-DEAD` | **Deadlock Management** | Deadlock Conditions, Resource Allocation Graph (RAG), Banker's Algorithm | CO3 |
| **06** | `MOD-MEM` | **Memory Management** | Fixed/Variable Partitioning, First Fit, Best Fit, Worst Fit, Next Fit, Fragmentation | CO3, CO4 |
| **07** | `MOD-VMEM` | **Virtual Memory** | FIFO, LRU, Optimal, LFU, Clock / Second Chance, Belady's Anomaly | CO4 |
| **08** | `MOD-FILE` | **File Systems** | Contiguous, Linked (Pointers), Indexed Allocation, Directory Structures | CO4, CO5 |
| **09** | `MOD-DISK` | **Disk Scheduling** | FCFS, SSTF, SCAN, C-SCAN, LOOK, C-LOOK Head Movement on Tracks 0-199 | CO5 |

Each experiment features:
- **Overview**: Objective, Prerequisites, Outcomes, Key Concepts
- **Theory**: Formatted cards, formulas, diagrams, common student mistakes
- **Algorithm**: Step-by-step logic breakdown
- **Simulation**: Interactive input, timeline Gantt/Visualizer, Step forward/back, Play/Pause, Speed 0.5x-4x
- **Code**: C / Bash starter template with simulated execution
- **Challenge**: Targeted problem with interactive feedback
- **Quiz**: Pre-test and post-test MCQs with explanations
- **Viva Voce**: Essential exam oral questions with revealable answers
